# 秋韵 · 琥珀回廊

为「计启秋韵」海报新增的独立样式。曲面顶棚、缎面铜饰、紫色陶釉和三层前景曲面形成不同的反光与投影。六片枫叶沿不同深度摆放，叶片折面和凸起叶脉均可在 Blender 中编辑。软件内可分别选择「枫光奏鸣」和「琥珀回廊」。

![外凸屏最佳观看点回贴](preview.jpg)

采用照片参考外凸预设。海报投影宽度约占可见屏宽 86.5%，保存工程中的原图纹理通过字节哈希校验，527 条海报视线全部无遮挡。播放画布为 4368×3120，海报覆盖率 100%，有效区 MAE 为 0.00353。最终使用 Blender 3.4.1 Cycles CPU 渲染，48 采样。156 项测试通过，浏览器实际上传、样式选择和快速预览通过。P3、90° 和观察点沿用照片参考参数，现场尺寸待测。
