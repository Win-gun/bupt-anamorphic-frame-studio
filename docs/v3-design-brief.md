# Aurora Space · V3 设计与验收约定

产品目标：上传普通图片即可形成柔和、开阔的三维图片展示空间。图片本身是视觉主体，不再默认制作传统画框。

视觉方向：低饱和灰蓝→烟紫→暖粉灰的连续曲面、薄悬浮面板和宽软投影。去掉默认金属压边、底座、墙柱、悬挂线、玻璃盖和框套框；V2样式作为Legacy完整保留。另新增建筑内嵌立方体，不与Aurora共用装饰造型。

工作顺序：先Aurora Float真实三配色渲染并看图迭代，确认默认方向；随后Soft Depth、Glass Layers和Embedded Cube；最后做创作/专业模式与预览。

界面：三栏工作台维持职责，创作模式默认只显示图片、风格、配色、面板/光照和预览导出；专业模式提供测量、机位、诊断和编码。系统字体与克制间距；灰蓝结构色、烟紫选中态、琥珀未校准。分隔线表达流程和参数层级，避免重复卡片。状态变更用短时透明度反馈，尊重Reduced Motion；渲染与动画由用户触发，不能自动耗费大量算力。

预览：完整场景、最佳点、有效LED裁切、展开分别标明；透明遮罩派生图允许换预览底色，不能改变播放画布。3D默认从作品真实朝向的正面三分之四视角打开，可旋转/缩放/重置。场地照片若提供，照片配准状态必须清楚，不能把手动叠图称为现场标定。

技术：沿用BUPT唯一像素预设、凹凸/安装朝向、固定相机逆投影、UV与独立回贴数值检查。渐变必须由真实曲面Shader Nodes计算，灯光/阴影参数真实作用于Blender；用户图片颜色与像素不受背景饱和度控制。

视觉验收：实际打开真实海报和通用素材输出，记录主图占用、原图完整性、背景是否发黑/过曝、渐变是否连续、阴影是否柔和、面板是否有前后关系。数值/几何结构测试与视觉复核分开；代理复核不冒充用户审美确认。

现场状态：P3/90°/曲率方向/观察机位仍未校准。未提供真实建筑照片，不宣称完成现场合成或对齐。
