# V2 视觉与工程验收约定

目标：让普通活动海报成为建筑虚拟舞台的主体，而不是缩小后塞进固定竖框。

视觉方向：深紫近黑的建筑开口、相机空间中合理透视的侧壁/顶/地面、分层磨砂金饰面、克制边缘高光。主体文字采用原海报贴图，完整显示优先。前景只承担空间尺度与遮挡线索。

界面延续三栏工作台与紧凑系统字体，用金色表示选中/输出，琥珀表示未校准；分隔线只表达面板职责和流程。快速/高质量/正式输出具有清楚的分辨率反馈。切换视图不改配置，渲染结果展示提交快照。加载/失败/验证未过必须可见，动画尊重 reduced-motion（手动触发，不自动播放）。

P0：保留已验证 UV 次序，新增整体一致的凹/凸符号与安装朝向。现场照片尚未提供，默认仍为兼容的凹面演示，凸面可切换；不能宣称已核对建筑。

自动构图在固定机位的投影可视遮罩内寻找安全矩形，按海报实际比例决定有效开口。输出画布始终为北邮预设比例。Auto Fit 改画框形状，Fill 必须报告 UV 裁切，Manual 明确暴露人工尺寸/位移。

验收分层：

1. 数值：接缝位置/切线、UV、正面/遮挡、有效屏幕回贴 MAE/PSNR。
2. 结构：画框连续多级截面、真实空间几何、海报比例、构图利用率、动态三维位置及逐帧曲面投影。
3. 视觉复核：实际打开渲染，观察主体大小、画面主题、墙体透视、材质高光、遮挡与文字可读性，保存意见及图片。
4. 最终用户美术确认：由用户决定。代理视觉复核与自动测试不能写成用户人工验收通过。

基线：V1 使用相同 1536×864 新建测试海报渲染以公平对比。该测试图不是用户的「计启秋韵」原稿。保留 V1 原样例与报告。
