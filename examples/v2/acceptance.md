# V2 验收记录 · 2026-11-09

本轮在既有仓库上开发，保留V1样例。全部测试使用1536×864紫金主题自制光栅图，**未测试用户「计启秋韵」原图**，未取得现场照片。

## 结果

- 57 项测试通过（含5组真实Blender回归）：`test-results.txt`。覆盖凹/凸、yaw、接缝/切线、遮挡、Auto Fit/Fill/Manual、四种比例、后墙约束、环形网格闭合与正面法线、配置保存/恢复/重置、上传和队列失败恢复。
- TypeScript/Vite 构建通过；主包约162kB，三维模块按需约638kB。构建器仍提示3D模块大于500kB，不影响本地工作流。
- npm audit 为0项漏洞：`npm-audit.json`。
- 浏览器上传、快速渲染、原画并排对照、GLB加载与旋转/缩放、保存/重置/JSON导入均实测通过；无页面异常，390px无横向溢出：`ui-check.json`。
- Blender打包工程与GLB为真实场景导出；独立复查GLB动画通道确认仅主框组件移动，建筑保持静态。

## 动画端到端

`scripts/v2_api_acceptance.py` 实际上传海报至本地API；6帧三维运动及扫光逐帧反投影，再由FFmpeg编码。`animation-api/led.mp4` 和 `video-probe.json` 记录546×390、6fps、1s H.264/yuv420p。0/3/5帧分别真实回贴验证，MAE0.010315/0.009935/0.010315，海报覆盖均100%。帧3处于最大位移停留段。

本短片用于验证真实运动及映射，并非全分辨率正式长视频。所有帧位移、动静对象清单和实际检查见 `animation-api/animation.json`。对应展开帧联系图为 `animation-api/mapped-motion-frames.png`。

## 美术与现场

实际视觉评价见独立文件 `visual-review.md`，不以MAE替代美术评价。V1/V2对比为同一海报的真实渲染，V2主体横版且更大，具备分层金属、实体墙/顶/地台和固定空间中的前景层。

P3/90°/曲率方向/yaw/观察点均是未校准演示参数。现场凹凸方向、真实物理尺寸、控制器展开顺序、镜头和LED响应仍需现场确认；用户人工美术确认待定。
