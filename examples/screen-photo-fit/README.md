# 北邮转角屏照片核查

两张现场照片的发光边界均显示外凸转角。以相同的 2704、416、1248 列和 3120 行建立平面—圆弧—平面模型，分别拟合两种曲率。两张照片独立估计机位、焦距和相机姿态，像素按 1368×1824 计算。固定 90° 时，四角与上下沿的加权重投影 RMS 为外凸 1.71 px、内凹 16.76 px。四角残差权重为上下沿残差的 2.5 倍。照片上的外凸圆弧顶点和两端可同时贴合。

早期预设采用内凹、偏高且靠左的观察点。它将原始屏幕下沿投影至 NDC −1.023，落在画布下边界之外。新预设采用外凸和由街景照片估算的低机位，重新瞄准屏幕中心，以 15° 水平视场显示完整轮廓。P3、90° 与估算机位属于照片参考参数，预设仍标注未校准。
